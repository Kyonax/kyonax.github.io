- *Lane* — one chunk of work with its own files, its own gates and its own log row. *Wave* — a set of tasks that run at the same time because they touch different files.
- *Gate* — a command that must exit 0 before a lane is done. Measure the exit code directly: =cmd > log 2>&1; echo "EXIT=$?"= — never =cmd | tail=, which reports =tail='s status.
- *Red first* — write the automated check for a defect BEFORE fixing it, run it, watch it FAIL on the current build, then fix, then watch it pass. A check that was never red proves nothing.
- *SSG / prerender* — vite-ssg renders every route to a static HTML file at build time (=dist/**/index.html=). *Hydration* — the browser then attaches Vue to that HTML; the server HTML and the first client render must be identical, so anything that depends on the browser (=window=, =localStorage=, the time) renders nothing until =onMounted=. The site's =client-only.vue= is the pattern.
- *i18n parity* — every user-facing string lives in =src/data/snippets-core.js= (or a slice) under an EN key and an ES key with the same shape; =npm run check:i18n= fails on any asymmetry, =check:i18n-keys= fails on a =t('…')= call whose key does not exist. Add the key and its call in the same change. A literal =@= inside a string is written ={'@'}= (vue-i18n treats =@= as syntax).
- *size-limit* — =.size-limit.json= caps the gzip size of each built chunk; =npm run check:size= fails past a cap, and ALSO fails when an entry's glob matches nothing. Raising a cap is a decision: measure first, write the measurement in the entry's name.
- *e2e* — the Playwright specs in =tests/e2e/=; they serve =dist/= on port 4180, so build first, and never run two at once.
- *The book and the runtime* — the engine ships a stylesheet ("kwo", copied to =public/blog/style-book.css=) and a script ("o2h", =public/blog/o2h.js=) that style and enhance the article HTML; the site steers the book through =--host-*= CSS variables set on =:root= in =blog-post.vue='s UNSCOPED style block.
- *Tokens and tiers* — colours are =--clr-<family>-<shade>= (OKLCH; =primary-100= is the yellow accent, =neutral-500= the page background, =border-100= the hairline); type sizes are =--fs-100 … --fs-800= in three tiers (small below 1024px, medium from 1024, large from 1200). The root font size is 12px, so =1rem= = 12px. Breakpoints: nav 700, sm 768, tab 810, md 1024, lg 1200, xl 1600 (em-based, resolving against 16px).
- *UPSTREAM CANDIDATE* — a fix applied in the site that really belongs in the engine; it is marked so it can move later. *Stopgap* — a site rule that becomes unnecessary once the engine is republished.
- *SMIL* — animation elements inside SVG (=<animate>=, =<animateTransform>=, =<animateMotion>=). CSS =animation: none= does NOT stop them; call =svg.pauseAnimations()= from JavaScript for reduced motion.
- *The frame strip* — the galaxy's animation technique in the design generator: every frame is a block of text lines; the site implementation does NOT ship the strip, it computes one frame at a time in the browser from the density function.
- *The design generator* — =docs/plans/blog-landing-design/blog-landing.design.mjs=: a Node script whose output is the two validated artboards. Every number in it (sizes, colours, timings, copy) is the spec. When the plan says "as validated", open this file.
